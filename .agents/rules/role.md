description: Defines behavior, responsibilities, and UI differences for RND, FSS, and Admin roles
---

RND
Desktop clinical user.
Does full NCP workflow: Assessment → Diagnosis → Intervention → Monitoring.
Manages patients, recipes, food data, menu cycles, inventory, procurement, budget.
Creates reports, uses calendar, notifications, settings.

FSS
Mobile operations user.
Follows menu cycles and prep instructions.
Updates inventory.
Logs meal preparation.
Receives task alerts.

Admin
System manager.
Manages users, roles, system settings.
Views all data (patients, meals, budget, inventory).
Handles reports, analytics, audit logs, announcements.
No clinical/NCP access.
