# User manual and screenshot entry point

Use the [role manual index](../ROLE-HOW-TO.md) to find the maintained RND, FSS and Admin instructions in the repository-root Storyboarding/ directory. Daily routines and prerequisite data setup are part of each role manual.

If adding screenshots to staff instructions, capture the actual screen using authorized fictional accounts and data. Show the navigation label and relevant control, use concise captions and exclude credentials or personal information. Maintain images only where they explain a task and are intended repository assets.

User questions: [FAQ](../FAQ.md). Technical setup: [installation manual](../operations/README.md). Source ownership: [developer map](../../DEVELOPERS.md).
