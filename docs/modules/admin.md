## Admin Module (Website)

Dashboard: system KPIs, charts(admissions/NCP completion/budget/inventory), activity feed
Users: create/edit/deactivate, assign roles, reset passwords
Announcements: create/pin/delete, visibility, read receipts
Audit Logs: full trail, filter, export
Settings: hospital info, budget thresholds, notification rules
Token Usage: daily/monthly chart from ai_usage_logs

### Reports

Admin has access to ALL report types across all users:

1. **ADIME Individual** — any patient's NCP summary
2. **ADIME Aggregate** — system-wide patient analytics
3. **NCP Census** — facility-wide demographics, malnutrition breakdown, ADIME completion metrics (B.08 reference, arbitrary date range)
4. **Inventory** — system-wide stock levels, expiry tracking
5. **Budget & Procurement** — system-wide spending, variance analysis
6. **Menu Cycle** — all menu cycles with costs/nutrition
7. **Patient Menu Plan** — any patient's meal plan
8. **Inspection Report** — all inspection records
9. **Marketing Statement** — all marketing purchase records

Report hub: filter by type, date range, generating user. Download any completed report.
