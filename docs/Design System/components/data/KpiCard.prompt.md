Metric tile — uppercase label, big tabular value, optional hint. Tone tints the whole tile.

```jsx
<KpiCard label="Cost / head" value="₱62.40" tone="neutral" hint="Limit ₱65.00" />
<KpiCard label="Out of stock" value="5" tone="red" hint="Needs restock" />
```
Tones: neutral | emerald | amber | red | sky.
