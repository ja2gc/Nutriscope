# NutriScope Role-Specific Help Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add searchable Help pages that expose shared questions plus only the authenticated role's guidance, reorganize the storyboard documents, and produce an updated installable FSS Android APK.

**Architecture:** The web app uses one reusable client component and a reusable disclosure list, with thin RND and Admin route wrappers passing a fixed role. The Expo app has a mobile-specific reusable disclosure list and FSS-only content. Both clients use local typed data and pure search helpers; no API, database, or cross-role content endpoint is introduced.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, Vitest, Expo Router, React Native, Node test runner, EAS Build.

- [ ] **Step 3: Implement pure role-bound filtering**

```ts
export function getVisibleHelpItems(role: WebHelpRole) {
  return HELP_ITEMS.filter((item) => item.role === "Shared" || item.role === role);
}

export function filterHelpItems(role: WebHelpRole, query: string) {
  const normalized = query.trim().replace(/\s+/g, " ").toLocaleLowerCase();
  const visible = getVisibleHelpItems(role);
  if (!normalized) return visible;
  return visible.filter((item) =>
    [item.question, item.answer, item.category, ...item.keywords]
      .join(" ")
      .toLocaleLowerCase()
      .includes(normalized),
  );
}
```
